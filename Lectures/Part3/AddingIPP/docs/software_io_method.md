# Software capitalization bridge

The BEA use table is observed under current accounting, in which software is
capitalized. Let purchased software be prepackaged plus custom software and
let own-account software be the separately reported NIPA component.

The reconstruction is:

```text
intermediate inputs before = intermediate inputs after + purchased software
value added before         = value added after - purchased - own account
gross output before        = gross output after - own account
```

Thus both columns satisfy `intermediate inputs + value added = gross output`.
The purchased-software change is a reclassification, while own-account
software records previously unmeasured production. This follows BEA's
description of recognizing intellectual property expenditures as investment.
